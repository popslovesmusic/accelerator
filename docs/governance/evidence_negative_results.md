# Evidence Negative Results (MPF-EVID-CAMP-007)

## 1. Purpose
Index and preserve all failed, null, and contradictory results from the evidence campaigns. This registry ensures that the framework's boundaries are defined as much by what it **cannot** explain as by what it can. Preservation of negative results is a non-negotiable requirement for scientific integrity and anti-cherry-picking governance.

## 2. Failure Classes
- **prediction_absent**: Primary dataset fails the signature test.
- **counterexample_match**: Adversarial dataset passes the signature test (indicates generic signature).
- **null_model_equivalent**: Results match random noise baseline.
- **metric_instability**: Signature is highly sensitive to noise or seeds.

## 3. Indexing Protocol
Every campaign, regardless of outcome, must be indexed. Successful campaigns are indexed in the evidence registries; all others are indexed here with a mandatory failure class assignment.
