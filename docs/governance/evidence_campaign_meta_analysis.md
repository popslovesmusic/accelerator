# Evidence Campaign Meta-Analysis (MPF-EVID-CAMP-009)

## 1. Purpose
Review the aggregate stability and specificity of evidence campaigns across multiple datasets, metrics, and controls. This meta-analysis ensures that support for mathematical signatures is not a fluke of a single data source, but is a robust and reproducible phenomenon across the entire evidence pipeline.

## 2. Stability Metrics
- **cross_dataset_consistency**: Do different datasets support the same prediction binding?
- **counterexample_resistance**: How consistently do adversarial datasets fail the signature check?
- **null_model_resistance**: How far above the noise floor is the primary signature?
- **signature_specificity**: Is the proxy metric uniquely tied to the predicted process logic?

## 3. Findings
Aggregate analysis confirms that the framework's core signatures (e.g., *threshold_discontinuity*) demonstrate high specificity and resistance to counterexamples.
