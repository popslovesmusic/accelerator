# Bounded Support Language (MPF-EVID-CAMP-008)

## 1. Purpose
Govern the exact language emitted after evidence campaigns to ensure that support for mathematical signatures is never misrepresented as "proof" or "reality." This generator enforces the framework's core claim-humility disclaimers by hardcoding mandatory phrases and prohibited terms into the final output logic.

## 2. Mandatory Phrases
Every support statement must include:
- **"Within these models and datasets..."**: Anchors the finding to specific context.
- **"restricted analog signature"**: Defines the object of support.
- **"bounded support"**: Quantifies the support strength.
- **"does not imply ontology confirmation"**: Primary governance disclaimer.

## 3. Implementation
The `generate_bounded_support_statements.py` script pulls from the `bounded_support_statement_registry.json` to produce standardized text for technical papers and reports.

## 4. Governance Boilerplate
- **Source Relation**: (E≠0) ⇔R δ(E>0)
- **Non-Separability Acknowledged**: true
- **Required Statement**: Observed signatures are interpreted only through restricted local analog structure.
