# Math-Bound Claim Emission Rules (MPF-DATA-MATH-009)

## 1. Purpose
Govern the exact language and semantic scope permitted when emitting support statements from dataset campaigns. These rules ensure that empirical evidence is never presented as "proof of truth" or "ontology confirmation," reinforcing the framework's core commitment to claim humility.

## 2. Mandatory Language
Every emitted claim must include:
- **"Within these models and datasets..."**: Mandatory starting phrase.
- **"restricted analog signature"**: Description of the findings.
- **"bounded support"**: Strength of the finding.
- **"does not imply ontology confirmation"**: Primary disclaimer.

## 3. Forbidden Terminology
The following phrases are strictly **prohibited**:
- `proof of theory`
- `confirmed ontology`
- `derived physics`
- `unified reality`
- `experimental proof of MPF`

## 4. Governance Boilerplate
- **Source Relation**: (E≠0) ⇔R δ(E>0)
- **Non-Separability Acknowledged**: true
- **Required Statement**: Observed signatures are interpreted only through restricted local analog structure.
