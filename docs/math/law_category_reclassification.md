# Law Category Reclassification (MPF-LAW-CONS-005)

## 1. Purpose
Reclassify each law into governed mathematical categories to clarify their role in the proof program. This classification helps identify which laws are foundational definitions, which are constraints on operators, and which are candidates for formal theorem derivation.

## 2. Category Definitions
- **definition**: Foundational process objects or operators.
- **operator_constraint**: Rules limiting operator domain, reach, or behavior.
- **projection_rule**: Governance for mapping source relations to observable analogs.
- **failure_rule**: Documentation of structural failure modes and boundaries.
- **derived_consequence_candidate**: Behaviors that emerge from core axioms but are not yet formal theorems.
- **theorem_candidate**: Core targets for the formal proof program (e.g., MT-series).
- **governance_constraint**: Rules ensuring framework compliance and non-separability.
