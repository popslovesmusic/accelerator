# Restricted Proof Candidate Phase Declaration (MPF-RPCR-001)

## 1. Purpose
Declare the proof-candidate review phase and freeze admissible proof language before theorem-specific work begins.

## 2. Phase Definition
- **Canonical Statement**: The restricted proof candidate review phase permits the formal evaluation of local theorem candidates (MT-001, MT-002, MT-003) under strict non-physical analog governance and explicit assumption declaration.
- **Short Form**: `proof_candidate_review := restricted_local_evaluation_only`
- **Non-Escalation Rule**: Review status does not constitute proof. No candidate may be promoted to 'PROVEN' status during this phase.

## 3. Governance Status
- **Theorem Status**: PROOF_CANDIDATE_REVIEW_ONLY
- **Series Status**: RESTRICTED_LOCAL_THEOREM_REVIEW
- **Scope Status**: STRICTLY_LOCAL_RESTRICTED_DOMAIN
- **Physics Status**: NON_PHYSICAL_ANALOG_MODEL
- **Readiness Basis**: READY_FOR_RESTRICTED_PROOF_CANDIDATES

## 4. Terminology Freeze
### Forbidden Terms
- `proven framework`
- `physical proof`
- `final theorem`
- `global closure`
- `QM/GR derivation`
- `unification proof`

## 5. Governance Rules
- **RPC-RULE-001**: Every proof candidate must explicitly declare all assumptions and restricted domain bounds.
- **RPC-RULE-002**: No proof candidate review may erase or hide active counterexamples.
- **RPC-RULE-003**: Local theorem derivation does not imply truth or ontology identity.
- **RPC-RULE-004**: All mathematical failures encountered during review must be preserved as structural information.

## 6. Forbidden Claims
- A supported candidate is a proven theorem.
- Local derivation readiness implies physical relevance.
- Theorem success proves global framework closure.
- Substrate alignment justifies QM/GR derivation.
