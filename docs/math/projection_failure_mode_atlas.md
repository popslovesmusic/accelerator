# Projection Failure Mode Atlas (MPF-PALG-028)

## 1. Purpose
This document establishes the **Projection Failure Mode Atlas**. It classifies the ways in which projection-derived structures (equality, implication, composition, biconditional, geometry, persistence, and orientation) can fail or be misinterpreted. The atlas provides formal categories for detecting "symbolic collapse" and prevents analytical shortcuts from escalating into unearned ontological or physical claims.

## 2. Core Rule: Failure Isolation
A failure in a projection (e.g., orientation overcompression or equality flattening) represents a limit of the analytical reduction, NOT an invalidation of the underlying **⇔R** source relation. Projections are non-reconstructible shadows; their collapse is expected at specific depth boundaries.

## 3. Failure Mode Classes

### 3.1 Symbolic Flattening Failures
- **PFM-001: equality_overflattening**: Mistaking $=$ for full $\iff_R$.
- **PFM-002: implication_sequentialization**: Mistaking $\to$ for primitive process order.
- **PFM-003: composition_chain_reification**: Mistaking $\circ$ for sequential construction.
- **PFM-004: biconditional_truth_flattening**: Mistaking `iff` for recursive closure.

### 3.2 Governance and Escalation Failures
- **PFM-005: projection_recoverability_overclaim**: Claiming a projection is reconstructive without trace metadata.
- **PFM-006: multi_projection_identity_error**: Mistaking agreement between projections for source identity.
- **PFM-010: physical_escalation**: Using projections to claim derivation of QM/GR or physical laws. **(CRITICAL RISK)**

### 3.3 Emergent Structure Failures
- **PFM-007: geometry_primitive_promotion**: Promoting geometry-like shadows to primitive status.
- **PFM-008: persistence_ontology_reification**: Treating persistence dynamics as independent ontology.
- **PFM-009: orientation_primitive_reification**: Treating projected orientation as independently fundamental.

## 4. Mitigation Rules
- **PFM-MIT-001**: Restore `source_relation` traceability immediately upon failure detection.
- **PFM-MIT-002**: Relabel any overflattened expression as `PROJECTION_ONLY`.
- **PFM-MIT-003**: Strictly reject any physical escalation stemming from projection agreement.
- **PFM-MIT-004**: Downgrade recoverability claims to `trace-recoverable` or `not-recoverable`.

## 5. Usage Rules
- **Banned**: Using the atlas to promote projection failures into theorem targets.
- **Banned**: Treating failure detection as proof of the source relation.
- **Banned**: Removing source traceability from failure records.
