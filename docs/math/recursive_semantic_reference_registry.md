# Recursive Semantic Reference Registry (MPF-RSEM-006)

## 1. Purpose
Formalize bounded recursive self-reference behavior without permitting closure absolutism or semantic self-completion.

## 2. Reference Classes
### 2.1 RSR_PARTIAL_SELF_TRACE
- **Class ID**: `RSR_PARTIAL_SELF_TRACE`
- **Definition**: Recursive reference that successfully traces part of its own history.

### 2.2 RSR_FEEDBACK_BOUND
- **Class ID**: `RSR_FEEDBACK_BOUND`
- **Definition**: Reference behavior constrained by mandatory feedback limits.

### 2.3 RSR_CONFLICT_STABILIZED
- **Class ID**: `RSR_CONFLICT_STABILIZED`
- **Definition**: Recursive structures that achieve stability by oscillating between opposing roles.

### 2.4 RSR_RECURSIVE_DRIFT
- **Class ID**: `RSR_RECURSIVE_DRIFT`
- **Definition**: Self-reference leading to semantic decay.

### 2.5 RSR_CLOSURE_BLOCKED
- **Class ID**: `RSR_CLOSURE_BLOCKED`
- **Definition**: Recursive pathways where self-completion is formally prohibited.

## 3. Mandatory Constraints
- **RSR-CON-001**: Recursive reference does not imply semantic closure.
- **RSR-CON-002**: Self-description remains bounded.
- **RSR-CON-003**: Recursive stabilization does not imply truth.

## 4. Governance Status
- **Theorem Status**: NOT_PROVEN
- **Scope Status**: STRICTLY_LOCAL_RESTRICTED_DOMAIN
- **Physics Status**: NON_PHYSICAL_ANALOG_MODEL

## 5. Governance Rules
- **RSR-RULE-001**: Every recursive semantic artifact must identify its feedback mode and depth limit.
- **RSR-RULE-002**: Claims of 'absolute semantic closure' trigger immediate `REJECT_ESCALATION`.

## 6. Forbidden Claims
- Recursive semantics proves that the framework is 'complete'.
- Self-reference derives the physical origin of information.
- Recursive stability justifies the assumption of an unconditioned source.
