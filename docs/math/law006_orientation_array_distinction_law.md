# LAW-006: Orientation Array Distinction Law

## Candidate Law Statement
### Informal
The local orientation operator $-(i)_\alpha$ and the distributed orientation array $\{-(i)_\alpha\}$ are distinct mathematical objects and must not be collapsed into a single layer.

### Local Operator Form
$$-(i)_\alpha := \text{local orientation-conditioned continuation operator at locus } \alpha.$$

### Array Form
$$\{-(i)_\alpha\} := \text{distributed orientation reconciliation topology over local orientation operators.}$$

### Object Class Distinction
The object $-(i)_\alpha$ and the object $\{-(i)_\alpha\}$ are not interchangeable: the first is a local/operator-like object (local orientation operator), while the second is a distributed/topological object (distributed orientation array).

### Array-Not-Collection Clause
$\{-(i)_\alpha\}$ is not treated as a simple unordered collection of local operators; it carries inherent relational, topological, recursion-density, and accessibility structure derived from distributed reconciliation.

### Transport Relation Clause
NavT acts between local orientation operators $-(i)_\alpha$, while CSI accessibility and recursion-density structure are formal properties of the distributed array topology $\{-(i)_\alpha\}$.

### Operational Distinction
$-(i)_\alpha$ acts locally on continuation and transport; $\{-(i)_\alpha\}$ governs distributed reconciliation density, accessibility topology, and ordering emergence.

### Transport Embedding
NavT operates between local $-(i)_\alpha$ operators, while CSI and recursion-density structure emerge from the array topology.

### Ordering Relation
Ordered continuation is generated through distributed admissibility-regulated reconciliation across $\{-(i)_\alpha\}$, not from isolated local operators alone. Apparent time\_app is a projection of this ordering.

## Context & Objectives
This law formally distinguishes the local mechanics of orientation-conditioned continuation from the global/distributed structures that emerge from their interaction. It prevents a common category error where the local operator is confused with the distributed topological array.

The primary objectives are:
- **Object Distinction:** Separate local operators from distributed topologies.
- **Topological Foundation:** Establish the orientation array as the basis for reconciliation density and transport accessibility.
- **Ordering Genesis:** Formally locate the emergence of ordering (and apparent temporality\_app) in the distributed array reconciliation, not the local operator.
- **Anti-Collapse Governance:** Prevent the introduction of a forced global orientation frame by maintaining the distinction.

## Law Conditions
1. **Local orientation operator explicit:** $-(i)_\alpha$ is defined as a local continuation operator.
2. **Distributed orientation array explicit:** $\{-(i)_\alpha\}$ is defined as a distributed topology.
3. **Local vs global roles distinguished:** Operational roles are separated and non-collapsible.
4. **NavT local operator dependency preserved:** Transport remains tied to local orientation states.
5. **CSI array topology dependency preserved:** Interaction domains emerge from the array structure.
6. **Recursion density emerges from array structure:** Distributed reconciliation governs recursion density.
7. **Ordering generated distributively:** Sequential ordering is an emergent property of the array.
8. **No local-global collapse:** Prevents flattening the framework into a single orientation layer.

## Failure Modes to Preserve
- **Local-Global Orientation Collapse:** Treating the local operator and the global array as the same object.
- **Array as Simple Collection Error:** Assuming the array is just a set without reconciliation topology.
- **Forced Global Orientation Frame:** Artifacts introduced by assuming a universal orientation.
- **Geometry\_proj as Primitive Leakage:** Assuming spatial geometry\_proj before orientation reconciliation.
- **Hidden Absolute Time\_app Reintroduction:** Assuming temporal ordering before array-governed recursion.
- **Distributed Reconciliation Loss:** Failing to account for the reconciliation between local orientation operators.
- **Orientation Operator Overextension:** Attributing global topological properties to local $-(i)_\alpha$.
- **Physics Claim Leakage:** Treating this mathematical distinction as a verified physical field\_phys.
