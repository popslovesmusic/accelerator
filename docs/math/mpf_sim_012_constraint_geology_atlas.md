# MPF-SIM-012: Constraint Geology Atlas

## 1. Purpose
This document performs the **formal documentation** for the constraint geology atlas (`MPF-SIM-012`). The goal of this atlas is to consolidate simulation evidence from admissibility groove formation, decay, reset dynamics, recovery paths, and hysteresis loops into a governed map of "constraint-geology" structures. It provides a terrain map for restricted-local proof eligibility.

## 2. Atlas Targets

### 2.1 Admissibility Groove Taxonomy (SIM012-T001)
- **Goal**: Classify stable, fragile, deceptive, residual, and scarred groove structures formed by recursive history.
- **Metric**: Groove classification.

### 2.2 Constraint Scar Mapping (SIM012-T002)
- **Goal**: Map irreversible or semi-irreversible deformation left by the activation of failure geometry blockers.
- **Metric**: Scar irreversibility score.

### 2.3 Recovery Geology (SIM012-T003)
- **Goal**: Classify whether recovered basins return to stability cleanly, elastically, plastically, or deceptively.
- **Metric**: Recovery class assignment.

### 2.4 Path-Dependent Basin Stratification (SIM012-T004)
- **Goal**: Layer basin behavior by its recursive history, decay state, and hysteresis loop characteristics.
- **Metric**: History-dependent stratification.

### 2.5 Proof Eligibility Terrain (SIM012-T005)
- **Goal**: Map which constraint-geology structures support formal review, require additional monitoring, or block proof use.
- **Metric**: Terrain-based proof eligibility.

## 3. Geology Classes
- **CG-STABLE-GROOVE**: Repeated admissible recursion forms a stable local pathway. Supports formal review.
- **CG-FRAGILE-GROOVE**: Admissibility pathway exists but remains threshold-sensitive. Review required.
- **CG-DECEPTIVE-GROOVE**: Pathway appears stable but masks hidden instability. Blocked.
- **CG-RESIDUAL-GROOVE**: Decayed memory weakly biases admissibility. Review required.
- **CG-ELASTIC-DEFORMATION**: Basin recovers with bounded deformation. Review required.
- **CG-PLASTIC-DEFORMATION**: Basin recovers but retains lasting deformation. Review required or blocked.
- **CG-SCARRED-REGION**: Persistent destabilizing structure from prior failure. Blocked.
- **CG-SEVERED-REGION**: Topology loses connectivity or boundary access. Blocked.
