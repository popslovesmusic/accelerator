# Loss Differential Clarity Metric (MPF-PALG-043)

## 1. Purpose
Measure whether QM-like and GR-like projection losses are clearly separated, weighted, and not collapsed into false complementarity.

## 2. Metrics Definitions
### 2.1 QM Loss Clarity
- **Metric ID**: `qm_loss_clarity`
- **Definition**: Measure of the explicit documentation and categorization of losses in QM-like projections.

### 2.2 GR Loss Clarity
- **Metric ID**: `gr_loss_clarity`
- **Definition**: Measure of the explicit documentation and categorization of losses in GR-like projections.

### 2.3 Loss Differential Separation
- **Metric ID**: `loss_differential_separation`
- **Definition**: Evaluates if QM-like and GR-like losses are recorded as distinct categories rather than overlapping.

### 2.4 Distortion Risk Explicitness
- **Metric ID**: `distortion_risk_explicitness`
- **Definition**: Measures whether projection distortion risks (over-discretization, over-smoothing) are explicitly flagged.

### 2.5 Overreading Risk Score
- **Metric ID**: `overreading_risk_score`
- **Definition**: Assesses the probability that losses are being ignored in favor of 'unification' claims.

## 3. Governance Status
- **Theorem Status**: NOT_PROVEN
- **Scope Status**: STRICTLY_LOCAL_RESTRICTED_DOMAIN
- **Physics Status**: NON_PHYSICAL_ANALOG_MODEL

## 4. Clarity Requirements
- `qm_loss_clarity >= 0.7`
- `gr_loss_clarity >= 0.7`
- `loss_differential_separation >= 0.8`

## 5. Governance Rules
- **LDC-RULE-001**: Low loss clarity scores block all bridge coherence promotions.
- **LDC-RULE-002**: Loss differential separation must be maintained to prevent false complementarity.

## 6. Forbidden Claims
- Loss differential clarity proves physical complementarity.
- Explicit distortion risks justify physical reification.
- Clarity scores replace the non-unification gate.
