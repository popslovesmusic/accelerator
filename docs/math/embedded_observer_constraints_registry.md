# Embedded Observer Accessibility Constraints Registry (MPF-RTOP-007)

## 1. Purpose
Define bounded reconstruction limits arising from embedded participation within projection systems.

## 2. Observer Constraints
### 2.1 No Complete Externality
- **Constraint ID**: `no_complete_externality`
- **Definition**: The observer cannot access the source relation from a privileged, non-process viewpoint.

### 2.2 Bounded Self-Description
- **Constraint ID**: `bounded_self_description`
- **Definition**: The projection containing the observer cannot fully describe its own mapping.

### 2.3 Observer Generated Tooling Constraint
- **Constraint ID**: `observer_generated_tooling_constraint`
- **Definition**: Analysis tools inherit the deformation modes of the projection.

### 2.4 Recursive Measurement Limit
- **Constraint ID**: `recursive_measurement_limit`
- **Definition**: Sequential measurements distort remaining recoverable residue.

### 2.5 Internal Reference Dependence
- **Constraint ID**: `internal_reference_dependence`
- **Definition**: Reconstruction accessibility is limited by available reference aspect roles.

## 3. Accessibility Bounds
- **EOA_LOCAL_ONLY**: Accessibility limited to local neighborhood.
- **EOA_PARTIAL_RECONSTRUCTION**: Possible but subject to structural gaps.
- **EOA_CONFLICT_LOCKED**: Blocked at boundaries by irreducible conflicts.
- **EOA_EXTERNALITY_BLOCKED**: Total reconstruction blocked by lack of external metadata.

## 4. Governance Status
- **Theorem Status**: NOT_PROVEN
- **Scope Status**: STRICTLY_LOCAL_RESTRICTED_DOMAIN
- **Physics Status**: NON_PHYSICAL_ANALOG_MODEL

## 5. Governance Rules
- **EOA-RULE-001**: Every reconstruction claim must specify embeddedness status and constraints.
- **EOA-RULE-002**: Claims of 'objective externality' or 'complete reconstruction' trigger immediate `REJECT_ESCALATION`.

## 6. Forbidden Claims
- Embedded observers can prove the full source relation.
- Tooling bias can be completely eliminated through refinement.
- Accessibility bounds derive the Heisenberg uncertainty principle.
