# Projection Loss Accounting Matrix (MPF-PALG-017)

## 1. Purpose
This document unifies the tracking of whole-relation features that are retained or lost when the primitive **⇔R** (residue-bound equivalence) is projected into secondary symbolic forms. It serves as a formal safeguard against mistaking analytical "shadows" for the holistic process core.

## 2. Source Relation: ⇔R
- **Interpretation**: Simultaneous Recursive Aspect-Binding.
- **Protected Features**: Residue History, Recursive Co-Generation, Aspect Simultaneity, Whole-Relation Indivisibility, Non-Separability Depth, Admissibility Context.

## 4. Loss Categories

### 4.1 Critical Loss
Loss of these features renders the projection ontologically incomplete:
- **Residue History**: Loss of transformation memory.
- **Recursive Co-Generation**: Loss of mutual aspect emergence.
- **Whole-Relation Indivisibility**: Loss of holistic structure.

### 4.2 Major Loss
- Aspect Simultaneity, Non-Separability Depth, Admissibility Context.

## 5. Forbidden Interpretations
The following interpretations are **STRICTLY PROHIBITED**:
- Treating any projected form ($=, \to, \circ, \iff$) as more primitive or fundamental than **⇔R**.
- Assuming projection loss can be ignored without invalidating the analytical result.
- Using projected forms to replace or overwrite the source relation in theorem-facing artifacts.
