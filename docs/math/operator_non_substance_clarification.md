# Operator Non-Substance Clarification

## 1. Purpose
This document clarifies that the primary operators of the Mono-Process Framework (δ, Π_A, NavT, Ξ, Arb_A, T_E) are **not** independent entities, agents, or substances. They are formal descriptions of the different inseparable aspects of the single root process relation.

## 2. Operators as Relational Aspects
An operator in this framework is a **formal descriptor of a process relation**, not an object that "does" the action.

### 2.1 δ is not an Actor
The continuation operator δ does not "decide" to act. It is the formal name for the **continuation aspect** of the core expression. The action is the inseparable process itself.

### 2.2 Π_A is not a Filter
The admissibility projection Π_A is not a "thing" that "filters" states. It is the formal name for the **residue-conditioning aspect** of the core expression. The filtering *is* the process of history constraining the present.

### 2.3 NavT is not a Messenger
The transport operator NavT does not "carry" information from one place to another. It is the formal name for the **spatial propagation aspect** of a continuation event.

## 3. Governance: No Reification of Operators
Under the Core Lock, it is strictly forbidden to describe operators as independent agents. They are facets of the single, unified process, and must be described in language that preserves this non-substantial, relational nature.
