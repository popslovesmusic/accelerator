# Campaign 005: Domain-Relative Entropy Projection Test

## Scope

This C1 campaign applies a frozen application projection to immutable Campaign 004 orientations. It does not retest or modify orientation.

## Directly observed/defined

The candidate projection is a deterministic domain-relative log-ratio over declared redistribution content. Its output retains the projection domain, projection primitive, relation identity, and the pre-projection orientation hash.

## Projection results

Across 700 serialized orientation pairs, projection stability, orientation preservation, inverse compatibility, relation-identity preservation, and deterministic hashing passed at 1.0. Independent verification reproduced all 700 results without reference values.

## Controls

Typed projection retained the tested orientation identities. Scalar, context-free, primitive-free, and domain-free controls discarded information. The application observable was not treated as orientation identity.

## External entropy comparison

The external comparison was documented but not run. Campaign 004 records contain no physical thermodynamic state variables. Adding such variables after projection freeze would violate the packet input contract, so no thermodynamic correspondence claim is made.

## Inferred inside framework

Within the executed records, a deterministic domain-relative projection can be layered over frozen orientations without changing orientation hashes or relation identities. Its inverse application observable is compatible with lawful orientation inversion.

## External resemblance (Analogy only)

The log-ratio resembles a change observable used in multiplicative state comparisons. This resemblance is not evidence of thermodynamic identity.

## What it does NOT prove

It does not show that entropy is identical to distinction density, that this projection is physically correct, or that conventional entropy behavior has been reproduced.

## Failure modes / uncertainty

The external comparison is non-comparable under the frozen input contract. The projection is one bounded candidate and is not a universal entropy definition.

## Status and next action

Status: `PROJECTION_SUPPORTED_NO_EXTERNAL_CORRESPONDENCE` (C1). A future campaign would need preregistered physical state fields and independent thermodynamic references.
