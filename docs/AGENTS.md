# Agent: Documentation and Report Scope

Applies to `docs/**` only.

## Authority

This file governs documentation, theory notes, technical papers, reports, and explanatory material.

Root `AGENTS.md` still applies unless this file explicitly grants narrower local writing permission.

## Allowed

- Edit documentation only when explicitly requested.
- Draft or revise reports using the applicable governance template.
- Label speculative, theoretical, historical, and empirical claims separately.
- Preserve citations, provenance paths, and claim classifications.

## Forbidden

- Treat historical documents as current runtime truth.
- Promote model evidence into universal proof.
- Remove uncertainty language from speculative claims.
- Rewrite archival notes as if they are current canonical state.
- Add empirical claims without recoverable evidence paths.

## Required Verification

For technical reports or papers:

- Identify source artifacts used.
- Mark whether each source is current evidence or historical residue.
- Ensure conclusions remain claim-humble.
- Run any available paper/governance gate if requested.
- Show `git diff -- docs/` after edits.

## Historical Residue Rule

Older documents may explain lineage, but they do not define current system health unless confirmed by current command evidence.
