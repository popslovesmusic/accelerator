# Theology Department Local Governance

This file is the local governance layer for `docs/theology/`.

It is subordinate to:
- `AGENTS.md`
- repository-root `GEMINI.md`
- `registry/compliance_charter_v2_3.json`
- `governance/claim_policy.json`
- `registry/governance/semantic_projection_policy.json`

## 1. Local Role

The theology directory is a department-local semantic interpretation layer.

It may:
- define theology-domain vocabulary,
- record structural analogies,
- stage department-local audits,
- maintain examples for governed comparison.

It may not:
- redefine global ontology,
- promote doctrinal claims from structure alone,
- use theology as a privileged foundation for the framework,
- treat analogy as identity,
- treat cross-domain portability as proof of external truth.

## 2. Mandatory Output Framing

All theology-facing outputs must use bounded language such as:
- "Within this framework..."
- "Within this department..."
- "This is a structural comparison..."
- "This does not establish doctrinal identity..."
- "This does not prove external theological truth..."

## 3. Department Interpretation Rule

Theology is treated as a semantic department rather than a mathematical foundation.

Department-local interpretation must preserve:
- process primacy,
- RT/Core indivisibility,
- whole-expression primacy,
- residue-conditioned history,
- semantic projection separation.

## 4. Local Claim Ceiling

Unless explicitly overridden by a governed patch:
- definitions are capped at `C0_definition`,
- internal formal mappings are capped at `C1_model_relative`,
- theological comparisons are capped at `C3_structural_comparison`.

No local file in this directory may claim external doctrinal proof, metaphysical confirmation, or historical confirmation.

## 5. Negative Triggers

The following patterns require rewrite or blocking:
- "RT proves theology"
- "the framework proves God"
- "the Trinity is mathematically derived"
- "Incarnation follows deductively"
- "theology is the foundation of the mathematics"

## 6. Local Review Question

Before finalizing theology-department text, ask:

"Is this sentence reporting a governed internal definition or comparison, or is it silently escalating into an identity/proof claim?"
