## 1. Abstract
The Mono-Process Mathematical Program has thus far relied on high-level operational definitions of admissibility ($\delta_a$). To close the smallest formal gap through which all structural claims must route, this paper introduces a minimal predicate semantics for admissible continuation. We define the admissibility predicate $P_{adm}(x, c, R, -(i)) \in \{0, 1\}$ and formally construct the admissibility filter $\delta_a$ from it. We then evaluate three foundational claims: (1) nonempty admissible image implies continuation exists; (2) empty admissible image triggers reorientation or collapse; and (3) admissibility is not automatically transitive. This minimal kernel establishes the foundational logic for MPF-Core-Minimal v0.1, independent of cosmology, gravity, or matter projections.

## 2. Introduction: The Admissibility Gap

## 3. Formal Definition of the Admissibility Predicate ($P_{adm}$)

### 3.1 The Predicate
We define the **Admissibility Predicate** $P_{adm}$ as a boolean-valued function that evaluates whether a candidate next-state $x'$ is legally accessible from a current state $x$ under local conditions. To preserve the separation between core logic and mechanism realization, the predicate is structured as a **conjunctive kernel** of constraint families ($\Gamma$).

**Definition 1: The Admissibility Predicate**
$$ P_{adm} : \mathcal{X} \times \mathcal{C} \times \mathcal{R} \times \mathcal{O} \to \{0, 1\} $$

The predicate evaluates to true if and only if all constituent constraint families are satisfied:
$$ P_{adm}(x', c, R, -(i)) = \Gamma_{\mathcal{E}} \land \Gamma_R \land \Gamma_T \land \Gamma_{\mathcal{O}} $$

### 3.2 Constraint Families ($\Gamma$)
The decomposition into constraint families allows the framework to define different legality rules for different mechanism classes (PDE, Graph, etc.) without altering the core logical kernel.

1. **Mismatch Preservation ($\Gamma_{\mathcal{E}}$):** Ensures non-null distinction maintenance. Formally, $\mu_{rel}(x') > 0$ and alignment with context thresholds.
2. **Residue Compatibility ($\Gamma_R$):** Ensures the transition satisfies history-conditioned legality (Principle 2.X).
3. **Topology Compatibility ($\Gamma_T$):** Ensures the resulting organization belongs to an admissible topological class. This evaluates a **Topological Organization Object** ($T$).

**Definition 2: The Topological Organization Object ($T$)**
$T$ is a typed constraint structure generated by process history that captures the admissibility-relevant organization of the process.
$$ T_t = (\Lambda_t, N_t, B_t, O_t, K_t, R_t) $$
Where:
- $\Lambda_t$: Connectivity/Adjacency relation.
- $N_t$: Nodes or Loci of distinction.
- $B_t$: Boundary structure.
- $O_t$: Orientation constraints.
- $K_t$: Closure class (knot invariant).
- $R_t$: Residue marks.

The constraint is satisfied if the candidate state's topology is compatible with the evolving admissibility structure:
$$ \Gamma_T(x', c, R, -(i)) = 1 \iff T(x') \in A_{adm}(t) $$

4. **Orientation Compatibility ($\Gamma_{\mathcal{O}}$):** Ensures directional compatibility with the current reference frame $-(i)$.

## 4. The Admissibility Filter ($\delta_a$)

With the predicate formally defined, we can rigorously define the admissibility filter $\delta_a$. Previously treated as a composite funnel ($\Pi_A \circ S \circ \text{Cand}$), we now define it precisely as the set-builder over the predicate.

**Definition 2: The Admissibility Filter**
Given a current state $x$ and context $c$, the admissibility filter $\delta_a(x; c)$ returns the set of all candidate states $x'$ for which the admissibility predicate evaluates to true.

$$ \delta_a(x; c, R, -(i)) = \{ x' \in \mathcal{X} \mid P_{adm}(x', c, R, -(i)) = 1 \} $$

The set $\delta_a(x; c)$ is the **admissible image** of the state $x$. It contains every mathematically legal continuation available to the process at the current step.

## 5. Claim 1: Nonempty Admissible Image Implies Continuation Exists

**Claim:** If the admissible image is nonempty, a continuation event exists.

**Proof:**
By the Primary Axiom, the root condition for the process is:
$$ (\mathcal{E} \neq 0) \iff_R \delta_a(\mathcal{E} > 0) $$

Let the admissible image be nonempty:
$$ |\delta_a(x; c)| > 0 $$

This implies there exists at least one $x' \in \mathcal{X}$ such that $P_{adm}(x', c, R, -(i)) = 1$.
Because $P_{adm}$ explicitly requires that $x'$ satisfies the context $c$, residue $R$, and orientation $-(i)$, $x'$ is a fully legal state. 

Under the $U_\Omega$ Universal Law Schema, if a legal candidate exists ($Q \neq \emptyset$), the Arbitration operator $\text{Arb}_A$ selects a transition $T^*$ using the Optimal Mismatch Principle ($O^*$). Since the set is finite and non-empty (or bounded and closed in continuous domains), an infimum exists, and a selection is guaranteed by the tie-breaking rules of $\text{Arb}_A$.

Therefore, the existence of a nonempty admissible image guarantees the selection of a transition $T^*$. A transition event exists. $\blacksquare$

**Conclusion:** **Supported.** The claim holds axiomatically within MPF-Core-Minimal.

## 6. Claim 2: Empty Admissible Image Triggers Reorientation or Collapse

**Claim:** If the admissible image is empty, the system must trigger either reorientation or a 0-state collapse.

**Proof:**
Let the admissible image be empty:
$$ \delta_a(x; c) = \emptyset $$
This implies that for all $x' \in \mathcal{X}$, $P_{adm}(x', c, R, -(i)) = 0$. 

By the definition of the Primary Axiom, if $\delta_a(x;c) = \emptyset$, then the right side of the biconditional $\delta_a(\mathcal{E}>0)$ fails. Since the relation is a necessity biconditional, the process cannot advance to a new state $x'$ under the current parameter set.

We must evaluate the parameters of $P_{adm}$: $x$, $c$, $R$, and $-(i)$.
1. Context $c$ is globally fixed for the transition set.
2. Residue $R$ is historically fixed at the current process step.
3. State $x$ is the current process identity.

Under these constraints, the only degree of freedom available to the process arbitration logic is the local orientation reference $-(i)$. The system enters the **Crisis Regime**.

The Navigation Transform (NavT) is invoked to evaluate the exhaustive set of alternative orientations $\mathcal{O}$.
1. **Reorientation:** If there exists at least one $-(i)_{alt} \in \mathcal{O}$ such that $P_{adm}(x', c, R, -(i)_{alt}) = 1$, the system selects a new orientation and continuation proceeds.
2. **0-State Collapse:** If for all $-(i)_{alt} \in \mathcal{O}$, $P_{adm}$ evaluates to $0$, the admissible image remains empty for all possible orientations. The distinction condition $(\mathcal{E} \neq 0)$ cannot be satisfied. The biconditional decouples, and process participation terminates.

Because $\mathcal{O}$ is the complete set of orientation references, this fork is **exhaustively defined** for the kernel. $\blacksquare$

**Conclusion:** **Supported.** The fork between reorientation and collapse is the only mathematically valid outcome of a null admissibility predicate.

## 7. Claim 3: Admissibility is Not Automatically Transitive

**Claim:** Admissibility is an intransitive relation. That is, $P_{adm}(x_1, c, R_0, -(i)_0) = 1$ and $P_{adm}(x_2, c, R_1, -(i)_1) = 1$ does *not* imply $P_{adm}(x_2, c, R_0, -(i)_0) = 1$.

**Proof by Counterexample:**
Admissibility relies on Formal Principle 2.X (Residue-Conditioned Topological Admissibility), which states that:
$$ A_{adm}(t+1) = F(A_{adm}(t), R(t)) $$
Therefore, the parameters of the predicate $P_{adm}$ evolve with each transition.

Let $x_0 \to x_1$ be a valid transition.
Therefore, $x_1 \in \delta_a(x_0; c, R_0, -(i)_0)$, meaning $P_{adm}(x_1, c, R_0, -(i)_0) = 1$.
The transition generates new residue $R_1 = \Psi(R_0, x_0, x_1)$ and a new orientation $-(i)_1 = \text{NavT}(-(i)_0, x_1, R_1)$.

Let $x_1 \to x_2$ be a valid transition.
Therefore, $P_{adm}(x_2, c, R_1, -(i)_1) = 1$.

We must test if $x_0 \to x_2$ is automatically admissible: $P_{adm}(x_2, c, R_0, -(i)_0) \overset{?}{=} 1$.
Because $R_0 \neq R_1$ and $-(i)_0 \neq -(i)_1$, the topological constraints evaluated by the predicate have changed. The state $x_2$ may be legally accessible from $x_1$ under the new constraints $R_1$, but absolutely prohibited from $x_0$ under the old constraints $R_0$. 

For example, a transition $x_1 \to x_2$ might require a residue bridge $R_1$ that does not exist at state $x_0$. Attempting the direct jump $x_0 \to x_2$ fails the residue check inside $P_{adm}$. $\blacksquare$

**Conclusion:** **Falsified (The claim of transitivity is falsified; the user's claim that it is NOT transitive is Supported).** Admissibility is fundamentally non-transitive due to the state-dependent evolution of residue and orientation.
