# L040 — Minimum Relational Closure (The Triangle Law / 3-Peak Rule)

## Statement
Stable relational distinguishability ($D > 0$) cannot be maintained in a 1st-order binary opposition. Structural persistence requires a minimum 3rd-order recursive loop (The Triangle) to provide the necessary orientational locking. Topologically, a knot requires a minimum of **3 crossings (peaks)** to achieve structural closure; a 2-crossing loop is unstable and "slides off" (collapses into symmetry).

## Dependencies
- Definitions: `knot_stabilization`, `minimum_crossing_number`, `symmetry_collapse`
- Assumptions: Binary relations cannot induce an orientational fixed point; the null state is forbidden.
- Prior lemmas: L036 (Ratchet Deformation / Knot Insight), L037 (Entity as Stabilized Continuation Mode)

## Proof (or Proof sketch)
1. Let $N$ be the number of relational process crossings (peaks).
2. For $N=2$ (binary opposition), the orientational references $-(i)_1$ and $-(i)_2$ are mutually exclusive but provide no circular reinforcement. The "knot" slides off the "rope" of the process, leading to $D \to 0$ (Null Collapse).
3. For $N=3$ (The Triangle), the three-way coupling induces a closed orientational topology. Each reference is anchored by the other two: $-(i)_3$ reinforces $-(i)_1-(-(i)_2)$.
4. This **3-Peak Lock** is the minimum configuration that allows residue $R$ to accumulate into a self-maintaining manifold.
5. Because the null state is forbidden ($\mathcal{E} \neq 0$), the process is structurally compelled to expand to $N \ge 3$ to achieve stable continuation.
6. Therefore, identity (thingness) is the minimum viable response to the prohibition of the null state.
