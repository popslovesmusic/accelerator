# L003 — Participation Boundary is a Boundary Condition (Not “Void”)

## Statement
Assume `csi(α) = ∅` and the update rule side of the core expression is evaluated/active for `α`. Then `xα` is a fixed point of the continuation step for `α`. In this sense, the “non-participating symmetry” regime can be treated as a boundary condition (a degenerate fixed point), not as an undefined state.

## Dependencies
- Definitions: D3 (Coupling neighborhood)
- Assumptions: none beyond those used by L002
- Prior lemmas: L002

## Proof sketch
By L002, under `csi(α)=∅` the update yields `x'α = xα`. This is precisely the fixed-point property for the continuation mapping at `xα`. ∎
