# Technical Note

## Biased Transport Communication via Phase Packets (SPM Framework)

### 1. Overview

We define a communication scheme in which information is not transmitted as symbols or signals in the conventional sense, but emerges from the **biased formation, persistence, and alignment of phase packets** within a shared or coupled medium.

A *phase packet* is a phase-coherent, bounded admissibility structure whose formation requires threshold activation and whose persistence depends on residue-supported continuation. This follows directly from the two-threshold structure and M-law dynamics previously established.

The key shift is:

> Communication = controlled induction of admissible continuation, not signal transmission.

---

### 2. Core Mechanism

The system consists of:

```json
{
  "transmitter_A": "injects epsilon (activation attempt)",
  "medium": "residue + admissibility structure (R, rho)",
  "receiver_B": "realizes packet based on local admissibility",
  "observable": "phase packet existence, persistence, and orientation"
}
```

The process:

1. A applies a forcing ε (epsilon)
2. The medium evaluates admissibility (M7)
3. A phase packet may form if ε > s_crit
4. The packet persists only if R > κ_crit
5. The receiver observes the realized packet state

---

### 3. Two-Threshold Encoding

Communication arises from the decoupling of formation and persistence:

```json
{
  "activation_threshold": "ε > s_crit → packet can form",
  "persistence_threshold": "R > κ_crit → packet can survive",
  "decoupling": "formation ≠ persistence"
}
```

This yields a natural encoding space:

| State      | Description                 |
| ---------- | --------------------------- |
| Null       | No packet forms             |
| Transient  | Packet forms but collapses  |
| Persistent | Packet forms and stabilizes |

This is not binary signaling but **state-based encoding in admissibility space**.

### 4. Bias and Transport

Biased transport is defined as:

> The propagation of asymmetry in admissibility that selectively favors certain phase packet realizations.

Formally:

```json
{
  "bias": "local asymmetry in admissibility",
  "transport": "propagation of admissibility conditions",
  "effect": "increased likelihood of specific packet formation and alignment"
}
```

The transmitter does not send the packet directly. Instead:

> It biases the field such that the receiver is more likely to realize a corresponding packet.

### 6. Geodesic Interpretation

A geodesic is reinterpreted as:

> A path of minimal admissibility cost defined by accumulated residue.

Let:

[
C(x,t) = C_0(x) - \alpha R(x,t)
]

Then preferred paths satisfy:

[
\text{Path}^* = \arg\min \int C(x(t),t),dt
]

Thus:

```json
{
  "geodesic": "minimum-cost continuation path",
  "cost": "inversely related to residue",

```
