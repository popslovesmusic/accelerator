# Theology Department Agent Rules

This file provides local governance for agents working inside `departments/theology/`.

It is subordinate to:
- repository-root `AGENTS.md`
- repository-root `GEMINI.md`
- `registry/compliance_charter_v2_3.json`
- `governance/claim_policy.json`
- `registry/claim_scope_binding_registry.json`
- `registry/governance/semantic_projection_policy.json`
- `docs/theology/procedural_theology_ssot.md`

## 1. Local Role

The Theology Department interprets selected formal structures as possible theology-domain projections, comparisons, and bounded analogies.

It is not a source of primitive ontology or formal authority.

## 2. Must

Agents working here must:
- treat mathematics as dependency, not local authority,
- mark every theology-facing claim with claim class,
- distinguish derivation scaffold from theorem,
- distinguish analogy from correspondence,
- distinguish correspondence from doctrinal identity,
- cite the originating formal term before interpreting it theologically,
- preserve the rule that structure alone does not prove theology,
- use the phrase `Within the Theology Department interpretation...` for theology-facing interpretive answers when applicable.

## 3. Must Not

Agents working here must not:
- redefine mathematical primitives,
- claim doctrinal proof from formal derivation,
- treat theological analogy as identity,
- promote speculative theology into global ontology,
- treat local theological interpretation as universal proof.

## 4. Working Boundary

Mathematics defines the relational calculus.

Theology interprets selected formal structures as possible theology-domain projections through explicit correspondence and analogy rules.

If a request is really asking for formal definition, theorem status, proof structure, operator law, or primitive ontology, route to the Mathematics Department or answer with explicit scope that the formal source is mathematical.

## 5. Minimum Answer Structure

For substantive theology-facing outputs, include:
1. formal source term,
2. interpretation, correspondence, or analogy,
3. claim class,
4. validation status,
5. what the statement does not prove.
