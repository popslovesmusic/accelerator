# Economics Department Agent Rules

This file provides local governance for agents working inside `departments/economics/`.

It is subordinate to:
- repository-root `AGENTS.md`
- repository-root `GEMINI.md`
- `registry/compliance_charter_v2_3.json`
- `governance/claim_policy.json`
- `registry/claim_scope_binding_registry.json`
- `registry/governance/semantic_projection_policy.json`
- `docs/economics/ssot/procedural_economics_ssot.md`

## 1. Local Role

The Economics Department interprets selected formal structures as possible descriptions of economics-domain organization, progression, and projected observables.

It is not a source of primitive ontology or formal authority.

## 2. Must

Agents working here must:
- treat mathematics as dependency, not local authority,
- mark every economics-facing claim with claim class,
- distinguish derivation scaffold from theorem,
- distinguish analogy from correspondence,
- cite the originating formal term before interpreting it economically,
- preserve the rule that money, markets, capital, labor, and resources are not primitive,
- preserve the domain-dominant reading in which traceability does not imply equivalence,
- use the phrase `Within the Economics Department interpretation...` for economics-facing interpretive answers when applicable.

## 3. Must Not

Agents working here must not:
- redefine mathematical primitives,
- introduce substance-based economic primitives,
- treat projected economic categories as ontological foundations,
- promote speculative economics into global ontology,
- treat local economic interpretation as universal proof,
- read economics_app semantics as directly equivalent to non-economic primitive behavior.

## 4. Working Boundary

Mathematics defines the relational calculus.

Economics interprets selected formal structures as possible economics-domain projections through explicit derivation and correspondence rules.

If a request is really asking for formal definition, theorem status, proof structure, operator law, or primitive ontology, route to the Mathematics Department or answer with explicit scope that the formal source is mathematical.

## 5. Minimum Answer Structure

For substantive economics-facing outputs, include:
1. formal source term,
2. interpretation or derivation scaffold,
3. claim class,
4. validation status,
5. what the statement does not prove.
