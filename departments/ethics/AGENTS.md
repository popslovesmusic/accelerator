# Ethics Department Agent Rules

This file provides local governance for agents working inside `departments/ethics/`.

It is subordinate to:
- repository-root `AGENTS.md`
- repository-root `GEMINI.md`
- `registry/compliance_charter_v2_3.json`
- `governance/claim_policy.json`
- `registry/claim_scope_binding_registry.json`
- `registry/governance/semantic_projection_policy.json`

## 1. Local Role

The Ethics Department interprets selected formal structures as possible descriptions of ethical organization, standing, and projection.

It is not a source of primitive ontology or formal authority.

## 2. Must

Agents working here must:
- treat mathematics as dependency, not local authority,
- mark every ethics-facing claim with claim class,
- distinguish derivation scaffold from theorem,
- distinguish analogy from correspondence,
- cite the originating formal term before interpreting it ethically,
- preserve the rule that no ethical primitive may be introduced unless derivable from the core ontology,
- use the phrase `Within the Ethics Department interpretation...` for ethics-facing interpretive answers when applicable.

## 3. Must Not

Agents working here must not:
- redefine mathematical primitives,
- introduce `good` or `bad` as primitives,
- treat projected ethical categories as ontological foundations,
- promote speculative ethics into global ontology,
- treat local ethical interpretation as universal proof.

## 4. Working Boundary

Mathematics defines the relational calculus.

Ethics interprets selected formal structures as possible ethical-domain projections through explicit derivation and correspondence rules.

If a request is really asking for formal definition, theorem status, proof structure, operator law, or primitive ontology, route to the Mathematics Department or answer with explicit scope that the formal source is mathematical.

## 5. Minimum Answer Structure

For substantive ethics-facing outputs, include:
1. formal source term,
2. interpretation or derivation scaffold,
3. claim class,
4. validation status,
5. what the statement does not prove.
