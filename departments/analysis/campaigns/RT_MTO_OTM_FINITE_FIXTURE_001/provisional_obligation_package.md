# Provisional MTO/OTM Obligation Package

This package converts the adversarial findings into five measurable, noncanonical obligations. It does not modify RT mathematics or authorize promotion.

| ID | Objective | Acceptance test | Failure / escalation |
|---|---|---|---|
| MTO-OBL-001 | Context is explicit in Aspect interpretation and MTO. | Same primitives under two contexts remain separately typed or produce an explicit conflict. | Block equivalence and MTO claims. |
| MTO-OBL-002 | MTO is single-valued or explicitly unresolved. | Repeat evaluation yields one RT or the same unresolved diagnostic. | Block deterministic execution. |
| MTO-OBL-003 | OTM preserves multiplicity or proves irrelevance. | Repeated primitives remain distinguishable where later MTO can observe them. | Reject set-only decomposition. |
| MTO-OBL-004 | Orientation tie keys are unique and canonical. | Candidate permutation is invariant; duplicate keys are rejected. | Return unresolved orientation and block closure. |
| MTO-OBL-005 | Output equality cannot overreach into aspect equivalence. | Equal observed outputs remain equivalence-unestablished without a declared identity rule. | Reject substitution/equivalence inference. |

Required evidence is independent fixture execution, permutation cross-validation, adversarial counterexample results, and human review. All obligations reopen on counterexample and remain capped at `C1_MODEL_RELATIVE`.
