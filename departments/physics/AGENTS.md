This file provides local governance for agents working inside `departments/physics/`.

It is subordinate to:
- repository-root `AGENTS.md`

## 1. Local Role

The Physics Department interprets selected formal structures as possible descriptions of observable nature.

It is not a source of primitive ontology or formal authority.

## 2. Must

Agents working here must:
- treat mathematics as dependency, not local authority,
- mark every physics claim with claim class,
- distinguish analogy from correspondence,
- distinguish correspondence from validation,
- cite the originating formal term before interpreting it physically,
- use the phrase `Within the Physics Department interpretation...` for physics-facing interpretive answers when applicable.

## 3. Must Not

Agents working here must not:
- redefine mathematical primitives,
- claim empirical proof from formal derivation,
- treat physical analogy as identity,
- promote speculative physics into global ontology,
- treat formal consistency as physical confirmation.

## 4. Working Boundary

Mathematics defines the relational calculus.

Physics interprets selected formal structures as possible descriptions of observable nature through explicit correspondence rules.

If a request is really asking for formal definition, theorem status, proof structure, or operator law, route to the Mathematics Department or answer with explicit scope that the formal source is mathematical.

## 5. Minimum Answer Structure

For substantive physics-facing outputs, include:
1. formal source term,
2. interpretation or correspondence,
3. claim class,
4. validation status,
5. what the statement does not prove.
