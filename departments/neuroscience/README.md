# Neuroscience Department

This directory is the peer root for the Neuroscience Department.

The live local SSOT is `departments/neuroscience/department_ssot.md`, and the local agent rules are in `departments/neuroscience/AGENTS.md`.

The department is inducted as an interpretive application layer. It models neural and cognitive organization as relational arrays, orientation fields, and phase-mismatch patterns without claiming primitive authority over neuroscience itself.
